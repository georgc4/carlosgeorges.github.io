Making a word game out of dice

Recast is a small rule with a lot hiding underneath it: roll letters, build a crossword, make every run a word.

CARLOS GEORGESPROJECT NOTE · 2026

Recast started with a question: what if a crossword were something you built from the letters you rolled? You get a set of letter dice and place them on a grid. Every horizontal and vertical run of two or more letters has to be a valid English word. That one constraint makes every placement affect the next one.

Designing the space behind the game

The iOS app is written in SwiftUI, but a lot of the work lives outside the app. I built a Python pipeline to curate words, cluster them, design dice, and check puzzle solvability before the data is bundled into the game. The app then handles placement, live validation, hints, and scoring across word quality, board geometry, and semantic coherence.

There are three board sizes, free play, and a daily puzzle. I wanted a game where a clever intersection feels as good as finding a long word. The scoring system rewards both, along with compact layouts and meaningful connections between words.

The surprising part was how much engineering it takes to make a puzzle feel simple.

Shipped, and still improving

Recast is live on the App Store. The recent update improved battery use and the daily puzzle system, expanded the accepted dictionary, and fixed visual issues. It is a different kind of engineering project for me, but it still has the same shape: build the whole pipeline, then find every place where the pieces disagree.
