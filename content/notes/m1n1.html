I contributed a small change to m1n1, the bootloader and experimentation environment used by Asahi Linux. It changes when a secondary CPU restores CNTHCTL_EL2 during hypervisor initialization on Apple M3 and later systems.

The final diff is four added lines and one removed line. The important part is the ordering those lines establish.

Configure the redirection first

On these systems, counter redirection needs to be configured and visible before writing CNTHCTL_EL2. The old initialization path restored that register earlier. My patch moves the write after the counter-redirection setup and places an instruction synchronization barrier, isb, immediately before it.

// For M3 and up, CNTHCTL_EL2 must be written after the counter redirection
sysop("isb");
msr(CNTHCTL_EL2, info->cnthctl);

The barrier is part of the change: it establishes the required visibility before the following register write. Moving a line of C farther down the function, by itself, doesn’t express that complete requirement.

The patch was merged on July 15, 2026. Its scope is specific: secondary-CPU hypervisor initialization in m1n1 on the affected Apple systems. The result is a short piece of code where the hardware requirement, synchronization point, and register write now appear together.
