RISC-V / RTL / LINUXIn progress

A RISC-V computer
running Linux.

I built an RV32 SoC with an Sv32 MMU, serial memory controllers, peripherals, and SBI firmware. It now boots Linux in Verilator, accepts a command over UART, and runs a separate program from BusyBox ash.

The shell originally got stuck after Linux printed “ready.” The culprit was an interrupt bit being latched during a CSR write. The acceptance test now types a command and checks the program’s output.
